## 3. Accounts on these services

Every human account on Vercel, the database host, Mux, Resend, Airtable, GitHub and the password manager must:

- belong to a named person, never be shared;
- have multi-factor authentication (passkey or authenticator app) switched on;
- be removed on the day the person leaves.

## 4. Secrets

All secret values (database URLs, API tokens, encryption keys) live **only** in the Vercel project's environment variables and, for local development, in untracked `.env.local` files. The repository lists names only (`apps/lms/.env.example`, `apps/lms/turbo.json`). CI fails if a tracked `.env` file or a value in `.env.example` appears, and runs a secret scanner (gitleaks) on every change.
