# SOP Library

An **SOP** (standard operating procedure) explains how a specific activity is carried out. Each SOP links to the [policy](/policies) that sets the rules behind it.

> [!NOTE]
>
> SOPs marked **Draft** were prepared from approved policies and still contain `[TBC]` items for the process owner to complete. Planned SOPs are listed so you can see where the manual is heading.

## Adding an SOP

1. Pick the category and the next free number. Create the file in that category's folder, named like `sop-trn-006-short-title.md`.
2. Add the page to the `_meta.js` file in the same folder, so the sidebar shows a readable title.
3. Move its row from **Planned** to **Drafted** in this page.
4. Follow [SOP-GOV-001 Document Control](/sops/governance/sop-gov-001-document-control).
