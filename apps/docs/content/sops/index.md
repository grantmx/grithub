## Numbering

SOPs are numbered `SOP-###`, and the file name matches the number, for example `sop-001-document-control.md`. Group related SOPs in a folder such as `general`, `operations`, or `programs`.

When you add an SOP, you also need to:

1. Add a row to the table above.
2. Add a short entry to the `_meta.js` file in the same folder, so the sidebar shows a readable title.
